# GIALLOVISION // CORE

**Interactive Nodal Portfolio Interface & Systems Architecture**  
A high-performance, browser-based experiential portfolio designed around the nodal workflow environments of professional media servers, generative AI pipelines, and live show engineering.

---

## ⚙️ Core Architecture

This application bypasses traditional website conventions in favor of an interactive, node-based workspace and modular layout. Visitors navigate through physical cable patching, dynamic page modules, and real-time parameter controls.

* **Frontend Engine:** Vanilla HTML5, CSS3, ES6 JavaScript
* **Nodal Framework:** [LiteGraph.js](https://github.com/jagenjo/litegraph.js) (Customized execution engine)
* **Background Rendering:** WebGL GLSL procedural shaders (Fluid dynamics & signal noise)
* **Hosting & CDN:** GitHub Pages + Cloudflare CDN Edge Network
* **AI Intelligence:** Integrated `L4G0TT0` instance powered by containerized LLM compute
* **Logging Pipeline:** Direct-to-sheet SOW logging engine with instant email dispatch

---

## 🌐 Navigation & Core Modules

### 1. WORK (`/work`)
A high-impact visual archive of selected projects, technical executions, and stage installations:
* Case studies spanning live visual design, complex media server setups, and generative assets.
* Asynchronous video streaming and high-resolution media playback.

### 2. SERVICES (`/services`)
A detailed breakdown of technical capabilities and architectural offerings:
* **Live Media Operations:** Resolume Arena, TouchDesigner, TouchOSC, and real-time playback control.
* **Spatial & Stage Design:** Vectorworks 3D pre-visualization, pixel-mapping, and scenic integration.
* **Nodal & Generative Workflows:** ComfyUI, custom LoRA training, and AI pipeline orchestration.
* **Infrastructure & Automation:** Proxmox, Docker containerization, and Ansible orchestration.

### 3. NODES (`/nodes`)
The flagship interactive workspace simulating media server environments:
* **Console / Boot Sequence:** Kernel telemetry and dynamic connection states.
* **Exosphere & Canopy Render:** Spatial LED mapping architectures and large-format canvas rendering.
* **KSampler & VAE Decode:** Generative diffusion parameters and real-time AI node pipelines.
* **TouchDesigner / OSC Input:** Live sample-and-hold control signal modulation.
* **Video Combine (VHS):** Primary output node rendering media assets inside the graph.

### 4. ABOUT (`/about`)
An in-depth profile of Joey Giallombardo’s background, production philosophy, systems design credentials, and software mastery across 10+ years of live events and technical design.

### 5. CONTACT (`/contact`)
The **Clear Comms** signal modal:
* Global overlay accessible anywhere across the platform.
* Captures project scope, timeline urgency (1–5 scale), and technical requirements without exposing raw email addresses to web scrapers.

## 🤖 L4G0TT0 // SYNTHETIC OPS

A persistent AI assistant docked at the edge of the interface:
* **Session Memory:** Retains full context across refreshes and site exploration via tab session state.
* **Statement of Work (SOW) Transmit:** Scrapes active chat conversations and converts technical discussions into a direct project inquiry.
* **Engineering Dispatch:** Captures name, email, urgency level, and full chat logs straight to core logging.
